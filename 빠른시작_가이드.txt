현재 상태:
✅ 백엔드 서버: 실행 중! (http://localhost:8000)
⚠️  프론트엔드 서버: 아직 실행 안 됨

════════════════════════════════════════════════════════

【 지금 바로 실행하기 】

▶ 1단계: Node.js 설치 (아직 안 했다면)
   
   https://nodejs.org/
   
   → "LTS" 버전 다운로드 (권장)
   → 설치 파일 실행
   → 설치 완료 후 PowerShell 재시작

▶ 2단계: 프론트엔드 실행
   
   → "2_프론트엔드실행.bat" 더블클릭!
   
   (처음 실행 시 패키지 설치로 5~10분 소요)

▶ 3단계: 브라우저에서 확인
   
   자동으로 열리거나, 직접 접속:
   → http://localhost:5173

════════════════════════════════════════════════════════

【 Node.js 없이 백엔드만 테스트 】

백엔드 API가 정상 작동하는지 확인:

→ 브라우저에서 http://localhost:8000/docs 접속

여기서 API를 직접 테스트할 수 있습니다!

예시:
- GET /api/v1/notices → 공지사항 조회
- POST /api/v1/ai/chat → AI 채팅 테스트

════════════════════════════════════════════════════════

【 완벽한 사용 환경 】

백엔드(실행 중) + 프론트엔드(실행 필요) = 완전한 프로그램!

백엔드만:     API 테스트 가능 (http://localhost:8000/docs)
프론트엔드까지: 실제 프로그램 사용 가능 (http://localhost:5173)

════════════════════════════════════════════════════════

【 요약 】

1. Node.js 설치 (https://nodejs.org/)
2. "2_프론트엔드실행.bat" 더블클릭
3. 브라우저에서 http://localhost:5173 접속
4. 프로그램 사용 시작! 🚀
