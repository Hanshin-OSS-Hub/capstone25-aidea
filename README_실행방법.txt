========================================
  AIdea 프로그램 실행 방법
========================================

[ 중요! ] 아래 순서대로 실행하세요!

────────────────────────────────────────

【 준비 사항 】

1. Node.js 설치 (프론트엔드용)
   → https://nodejs.org/ 에서 LTS 버전 다운로드
   → 설치 후 컴퓨터 재시작 권장

2. PostgreSQL 실행 확인
   → 로컬 PostgreSQL이 실행 중이어야 합니다
   → 데이터베이스: aidea_db

────────────────────────────────────────

【 실행 순서 】

1단계: 백엔드 서버 실행
   → "1_백엔드실행.bat" 파일 더블클릭
   → 검은 화면(터미널)이 열리고 서버가 시작됩니다
   → "Uvicorn running on http://0.0.0.0:8000" 메시지 확인
   → 이 창을 닫지 마세요!

2단계: 프론트엔드 서버 실행
   → "2_프론트엔드실행.bat" 파일 더블클릭
   → 처음 실행 시 패키지 설치가 진행됩니다 (5~10분 소요)
   → 자동으로 브라우저가 열립니다
   → http://localhost:5173 주소로 접속됩니다

3단계: 프로그램 사용
   → 브라우저에서 AIdea 프로그램이 실행됩니다!
   → 공지사항, 캘린더, AI 도우미 등을 사용하세요

────────────────────────────────────────

【 주요 기능 】

✅ 대시보드: 오늘의 일정과 관심 공지 확인
✅ 전체 공지: 92개의 실제 한신대 공지사항
✅ 캘린더: 일정 관리 (추가/수정/삭제)
✅ AI 도우미: 챗봇으로 공지사항 검색
   예시: "최근 공지사항 알려줘"
        "마감 임박한 공지 보여줘"
        "장학금 관련 공지 찾아줘"

────────────────────────────────────────

【 프로그램 종료 】

1. 브라우저 창 닫기
2. 프론트엔드 터미널 창에서 Ctrl+C 또는 창 닫기
3. 백엔드 터미널 창에서 Ctrl+C 또는 창 닫기

────────────────────────────────────────

【 문제 해결 】

Q. Node.js 설치 후에도 명령어를 찾을 수 없다?
A. PowerShell/명령 프롬프트를 완전히 종료 후 재시작
   또는 컴퓨터 재시작

Q. 백엔드 서버가 안 열린다?
A. .env 파일에서 DB 연결 정보 확인
   PostgreSQL이 실행 중인지 확인

Q. 프론트엔드에 데이터가 안 보인다?
A. 백엔드 서버(1단계)가 실행 중인지 확인
   브라우저 F12 → Console 탭에서 에러 확인

Q. 포트가 이미 사용 중이라는 오류?
A. 다른 프로그램이 8000번(백엔드) 또는 
   5173번(프론트엔드) 포트를 사용 중
   해당 프로그램 종료 후 재실행
